# Original article reference

`encode-policy-original/` is a byte-for-byte copy of the production bundle committed for PolicyEngine's
“Automating Tax and Benefit Policy Modeling with Multi-Agent AI” interactive article.

The original uncompiled React source was never committed to `policyengine-app-v2`. These files are retained to
make comparisons with the older article exact and auditable. Make future article changes in `src/`, not in the
minified reference bundle.
